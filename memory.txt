------------------------------------------------------------------------
THE CHRONOLOGICAL TIME-MAP & EVOLUTION OF THE DESIGN
------------------------------------------------------------------------

● PHASE 1 THE INITIAL BLANK CANVAS & SKETCH
  - User shared initial ideas, MS Paint sketches, and an exact blueprint 
    for a Character Select style Socials page.
  - Claude's initial interpretation leaned toward Editorial Brutalism 
    (Courier PrimeBebas Neue fonts, off-white paper-like background, 
    thick ruled borders, zine-inspired layout).
  - RESULT Too static, too structural, and too corporatenews-source. 

● PHASE 2 THE UNDERGROUND HYPERPOP REBOOT (The Turning Point)
  - Crucial course correction from the user. The website is fundamentally 
    about underground music production Hyperpop, Breakcore, Dubstep, 
    Game Remixes, 808 beats, and high-speed chase tracks.
  - The Windows 95editorial look was completely scrapped for something 
    modern, hyper-stimulating, dark, and underground.
  - Color shift Dropped the paper colors and neon acid green. Picked up a 
    deep, near-black (#090909), dark purplesviolets for surfaces, and a 
    sleek dark blue (#93b4e8 on #0d1829) for active navbar highlights.
  - Typography shift Shifted to heavy, geometric 'Unbounded' for display, 
    quirky 'Syne' for UIbody, and techDAW-playlist inspired 'Fragment Mono'.

● PHASE 3 THE CODE ARCHITECTURE & THE SOCIALS BUILD
  - User decided to focus purely on the Socials page first to get it perfect, 
    leaving genresmusic for a later step.
  - User requested the navigation system to NOT scroll down a long page. 
    Instead, it must fade out the current page view and fade in the next one, 
    occupying ~90% of the screen seamlessly.
  - Claude generated a full React + Vite codebase, initializing pages as 
    stubs and fully building the Socials Page layout logic using AnimatePresence.
  - Current operational state App opens directly into the Socials page for testing.

● PHASE 4 WORKFLOW OPTIMIZATION (Where We Interrupted)
  - User realized exchanging raw code via ZIP files is incredibly tedious.
  - Discussed migrating to toolsets like Claude Code (CLI terminal interface) 
    or a dedicated VS Code extension setup for live-editing the folder.
  - The conversation paused precisely as we were getting ready to implement 
    and perfect the complex hover behaviors for the Socials character screen.

------------------------------------------------------------------------
EXACT RULES OF THE DESIGN MEMORY (Keep consistent moving forward)
------------------------------------------------------------------------
1. The Navigation Handles state switching. Clicking a link must smoothly 
   fade out the active component and fade in the new one. No scrolling.
2. The Socials Panel (Character Select Screen)
   - Default Muted, dark, grayed-out to blend into the background.
   - Hover Smooth pop-out scale animation. Background shifts to the brand 
     color (YouTube Red, Discord Blurple), but handled smartly so icons 
     don't bleed or lose contrast.
   - Quoted Text A specific, conversational quote (e.g., Discord Best place 
     to contact me) pops out on top of the grid card upon hovering.
   - Action The entire box is a giant, satisfying link wrapper.
